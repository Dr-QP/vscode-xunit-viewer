# Change Log

All notable changes to the `ros2-xunit-viewer` extension are documented in this file.

## [0.1.0] - 2026-03-07

### Added

- Initial Dr.QP workspace extension that embeds `xunit-viewer` for ROS 2 test results.
- Commands to open and refresh generated XUnit reports inside a VS Code webview.
- Configurable results path, output path, title, and ignore patterns.
